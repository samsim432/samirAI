# 🤖 SamirAI

Private Local AI Assistant powered by Ollama.

## Features

- 🧠 Local AI with Ollama
- 💬 Multi Chat Conversations
- ⚡ Streaming Responses
- 📄 PDF & TXT Analysis
- 📝 Markdown Rendering
- 🔒 Privacy First
- 💾 Local Chat Storage
- 🌐 Open Source

## Tech Stack

- React + Vite
- Node.js + Express
- Ollama
- Qwen 2.5
- Multer
- React Markdown
