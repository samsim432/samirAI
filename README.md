# SamirAI

SamirAI is a private local AI assistant created by Samir Simkhada.

## Features

- Local AI using Ollama
- React frontend
- Express backend
- Multi-chat sidebar
- Streaming responses
- Markdown support
- PDF and TXT upload
- Private data stays on your computer

## Requirements

- Node.js
- npm
- Ollama

## Install

```bash
git clone https://github.com/YOUR_USERNAME/samirAI.git
cd samirAI
./install.sh
